Your Language Model is Its Own Critic

Reinforcement Learning with Value Estimation from Actor’s Internal States

Yunho Choi*, Jongwon Lim*, Woojin Ahn, Minjae Oh, Jeonghoon Shim, Yohan Jo†

*Equal contribution. †Corresponding author.

Updated for arXiv v3 · October 1, 2026 revision

Paper arXiv Code BibTeX
TL;DR

POISE uses a lightweight probe over the actor's internal states to estimate a value baseline. Two independent rollouts supply each other's baselines, preserving the unbiased policy-gradient estimator. Across six-domain RL training, POISE improves the overall benchmark average on Qwen3-4B and OLMo-3-7B-Instruct-DPO.

What is this paper about?

Reinforcement learning with verifiable rewards trains language models from outcome feedback, such as whether a final math answer is correct. To turn those raw rewards into useful policy-gradient updates, RL methods usually subtract a baseline, so the update reflects whether a response did better or worse than expected for the prompt. GRPO estimates this baseline from multiple responses to the same prompt. Under a fixed rollout budget, larger groups leave fewer distinct prompts in each batch. PPO instead trains a separate policy-scale critic. POISE learns a baseline from the actor's hidden states and token entropy, using two rollouts per prompt and updating a small probe alongside the policy.

Introduction

Why internal value estimation matters

Stable multi-domain RL needs both a reliable baseline and diverse prompts in each batch. With the total rollout budget fixed, more responses per prompt reduce prompt diversity. POISE combines a learned baseline with just two rollouts per prompt.

No separate critic model

Instead of training another language-model-sized network, POISE uses the actor's internal states.

More prompts per batch

With the same rollout budget, POISE uses two responses per prompt, versus eight for the DAPO baseline.

Stable online learning

The estimator is updated as the policy changes, using current and recent rollouts.

Preliminary

Internal states carry a usable value signal

Before using internal states inside RL training, POISE first tests whether they can support prompt-level value estimation. The comparison spans five datasets and four policy backbones, including GPT-OSS-120B. The figure below shows Qwen3-4B on DAPO-Math.

Internal states are predictive

The internal-state probe reaches Pearson r = 0.870 and MAE = 0.141 on the preliminary benchmark, indicating that verifier-reward information is accessible from the actor's own forward-pass signals.

Competitive with a large critic

The comparison critic is finetuned from Qwen3-4B, but reports r = 0.676 and MAE = 0.262 in the same setting. This critic reads the prompt alone; the probe also observes generated trajectory features. Both use the same reward-labeled training data.

Method

Cross-rollout value estimation

A baseline derived from the same response can bias the policy gradient. POISE predicts each response's baseline from the other independently sampled response. The probe is trained against rewards from other rollouts, so its target is expected prompt-level reward.

1

Generate two answers

The old policy samples two independent responses for each prompt.

2

Read internal signals

Mean-pool the final prompt and reasoning token states; average token entropy separately over all generated, reasoning, and answer tokens.

3

Swap predicted values

Each response subtracts a value estimated from the other response, preserving independence.

4

Update the estimator

Compute baselines before fitting on the current batch. Then fit the ridge probe using paired-rollout rewards and a buffer of recent trajectories.

Results

Higher overall scores across reasoning domains

On the six-domain GURU training corpus, POISE achieves the highest overall benchmark average among the main baselines on both backbones: 1.35 points above DAPO on Qwen3-4B and 1.96 points on OLMo-3-7B-Instruct-DPO.

Six training domains, 17 evaluation benchmarks

Training uses 92K verifiable prompts with an equal compute budget across methods. Evaluation covers the six training domains, plus LiveBench and instruction following. Checkpoints are selected on the validation split. POISE and RLOO use two rollouts per prompt; DAPO uses eight.

Analysis

What the estimator is actually learning

Controlled ablations test the input features and cross-rollout construction. Additional experiments compare POISE with token-level PPO and assess value prediction across domains and model scales.

Tracks policy drift

Online analyses evaluate the estimator every 40 training steps against empirical Avg@8 values from the current actor checkpoint, testing whether it remains useful as the policy changes.

Works beyond math

Held-out value prediction spans math, coding, tool calling, and instruction following on four backbones, including GPT-OSS-120B. The probe improves MAE in 16 of 20 model–dataset pairs and Pearson correlation in 18 of 20.

Mostly linear signal

The linear ridge probe matches or exceeds the tested MLPs in Pearson correlation, although some MLPs have lower MAE. Combining prompt states, reasoning states, and entropy gives the best prediction in the input-feature ablation.

Cross-rollout ablation

In controlled Qwen3-4B math training, full POISE reaches 50.1% Avg@32 across seven benchmarks, versus 40.7% for the same-rollout variant and 47.5% for a prompt-only estimator. Both variants use one rollout per prompt; full POISE uses two. Table 3.

Comparison with token-level PPO

On the main multi-domain suite, POISE scores 58.10 versus PPO's 57.24 on Qwen3, and 49.92 versus 49.33 on OLMo. PPO uses a separate full-parameter token-level critic and one rollout per prompt. PPO is stronger in some individual domains. Table 11.

Instruction-following training. Instruction following is held out from the main GURU training mixture. In a separate experiment trained on IF-RLVR, POISE achieves the best IFEval and IFBench scores among the compared methods on Qwen3-4B and DeepSeek-R1-Distill-Qwen-1.5B. Table 8.
